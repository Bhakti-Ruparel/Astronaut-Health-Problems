# AstroMind

NASA-inspired astronaut health monitoring interface (hackathon prototype). All data is fictional, simulated demo data. Not affiliated with or endorsed by NASA. Monitoring indicators, not medical diagnoses.

## Run

```
npm install
npm run dev
```

Build: `npm run build`. Preview the build: `npm run preview`.

Stack: React, TypeScript, Vite, Tailwind CSS v4 (`@tailwindcss/vite`), React Router, Recharts, Lucide React, Inter and JetBrains Mono via @fontsource.
